1Шаг

Выберите учебную GenAI-задачу и запишите, какой реальный результат должен дать адаптер.

2Шаг

3Шаг

4Шаг

5Шаг

7Шаг

8Шаг

Выберите базовую модель и зафиксируйте её точное имя или revision.

9Шаг

Определите стоимость full fine-tuning и запишите главный риск для эксперимента.

10Шаг

11Шаг

14Шаг

15Шаг

16Шаг

18Шаг

Чек-лист самопроверки

  • Есть цель и понятный результат мини-работы.
  • Выбранная конфигурация связана с задачей и ограничениями.
  • Есть validation или контрольные prompt, а не только train loss.
  • Записаны риски: память, переобучение, несовместимость базы и адаптера.

план LoRA/QLoRA и проверка рисков
from peft import LoraConfig

def lora_params(d_in, d_out, r, modules=1):
    return modules * r * (d_in + d_out)

config = LoraConfig(
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    target_modules=["q_proj", "v_proj"],
    task_type="CAUSAL_LM",
)
print(lora_params(4096, 4096, config.r, modules=2))
