Мини-лаба: настроить QLoRA для слабой видеокарты

Рабочий сценарий вместо абстрактного конспекта: вы действуете как ML/LLM-инженер, которому нужно принять решение с ограничениями по данным, GPU и качеству.

Рабочий сценарий

Команда хочет обучить 13B-модель на 16 GB VRAM. Обычный LoRA запуск падает с OOM.

Цель

составить QLoRA memory plan: NF4, double quant, checkpointing, accumulation и ограничения context length.

Исходные ограничения

GPU 16 GB13B base modelдлинные примеры до 4096 токеновнужно сохранить качество
1Этап

Включите 4-bit NF4 для base model.

2Этап

Выберите batch и gradient accumulation.

3Этап

Решите, нужен ли gradient checkpointing.

4Этап

Снизьте sequence length или rank при OOM.

5Этап

Опишите, чем пожертвуете первым.
