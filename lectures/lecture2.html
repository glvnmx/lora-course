Что такое PEFT и зачем нужен LoRA-адаптер

PEFT — это семейство способов адаптировать модель без обучения всех весов. LoRA важна не сама по себе, а как практичный компромисс между prompt-only подходом и полным fine-tuning.

Зачем это нужно в работе

На работе ML-инженер выбирает метод под задачу, ограничения и риск. Иногда достаточно промпта, иногда нужен adapter, а иногда проект требует полноценной перестройки модели. PEFT-карта помогает объяснить этот выбор продуктовой команде.

Ключевые понятия

Подробное объяснение простым языком

Prompt tuning и prefix tuning учат небольшие добавки вокруг входного контекста. Adapters добавляют отдельные слои внутрь модели. LoRA встраивает низкоранговую ветку в существующие линейные проекции, поэтому хорошо подходит для LLM SFT и поддерживается зрелым tooling.

Выбор PEFT-метода зависит от того, насколько нужно изменить поведение модели. Если нужен только формат ответа, prompt может быть достаточен. Если нужен устойчивый стиль, терминология или новая процедура ответа, LoRA часто даёт более предсказуемый результат.

Технический блок

В Hugging Face PEFT один и тот же base model можно использовать с разными адаптерами: support-style, legal-draft, json-extractor. Это удобно для A/B-тестов и rollback: меняется маленький adapter, а не вся модель.

Типичные ошибки

  • Выбирать LoRA автоматически, не проверив prompt-only baseline.
  • Смешивать в одном адаптере разные задачи с конфликтующими форматами.
  • Не фиксировать base model revision, из-за чего адаптер потом сложно воспроизвести.

Мини-кейс ML/LLM-инженера

Команда юридического продукта просит модель писать черновики в фиксированной структуре. Prompt-only работает нестабильно, full fine-tuning дорог. Инженер выбирает LoRA, потому что задача требует устойчивого формата, но не новых фундаментальных знаний.

Короткое резюме

  • PEFT — не один метод, а семейство экономной адаптации.
  • LoRA — сильный старт для доменных LLM-задач с ограниченным бюджетом.
  • Метод выбирают по изменению поведения, данным, памяти и требованиям к деплою.
