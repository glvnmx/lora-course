Практическое задание 2. Математические основы низкоранговых разложений

Короткая тренировка после лекции: одно задание, которое закрепляет главный навык темы.

Посчитайте параметры LoRA

Для слоя 4096 x 4096 рассчитайте число параметров LoRA при r = 8, 16 и 64. Используйте формулу r * (d_out + d_in).

d_out = 4096
d_in = 4096
for r in [8, 16, 64]:
    params = r * (d_out + d_in)
    full = d_out * d_in
    print(r, params, f"{params / full * 100:.2f}%")
