Связь с лекцией: сначала перечитайте «Как сохранить, использовать и выложить LoRA-адаптер», затем выполните шаги ниже по порядку.

1Шаг

Выберите финальную задачу и запишите, какой реальный результат должен дать адаптер.

2Шаг

Опишите baseline: как базовая модель решает задачу до дообучения.

3Шаг

Сформулируйте, почему простого prompt недостаточно или где он может быть достаточен.

4Шаг

Запишите ограничение по данным, времени и GPU-памяти.

5Шаг

Свяжите задачу с темой лекции: Как сохранить, использовать и выложить LoRA-адаптер.

6Шаг

Подготовьте один пример instruction-формата: system, user, assistant.

7Шаг

Проверьте данные: дубликаты, роли сообщений, длины примеров и отсутствие утечки validation.

8Шаг

Выберите базовую модель и зафиксируйте её точное имя или revision.

9Шаг

Определите adapter_config и запишите главный риск для эксперимента.

10Шаг

Выберите adapter_model как инженерное решение и объясните trade-off.

11Шаг

Задайте стартовые target_modules и объясните, почему они подходят архитектуре.

12Шаг

Задайте r, lora_alpha и lora_dropout для первого запуска.

13Шаг

Посчитайте или оцените число обучаемых параметров для выбранного rank.

14Шаг

Решите, нужен ли QLoRA, и запишите, что изменится в memory budget.

15Шаг

Составьте минимальный план обучения: batch, sequence length, learning rate, validation split.

16Шаг

Опишите, какие логи и метрики будете смотреть во время обучения.

17Шаг

Подготовьте eval-набор: baseline, validation, контрольные prompt и ручная рубрика.

18Шаг

Сформулируйте критерий успеха и критерий отката адаптера.

19Шаг

Запишите, какие артефакты нужно сохранить вместе с адаптером.

20Шаг

Соберите итоговый результат: карточка проекта и инструкция загрузки adapter_config/adapter_model для публикации.

Чек-лист самопроверки

  • Есть цель и понятный результат мини-работы.
  • Выбранная конфигурация связана с задачей и ограничениями.
  • Есть validation или контрольные prompt, а не только train loss.
  • Записаны риски: память, переобучение, несовместимость базы и адаптера.

from peft import LoraConfig

def lora_params(d_in, d_out, r, modules=1):
    return modules * r * (d_in + d_out)

config = LoraConfig(
    r=16,
    lora_alpha=32,
    lora_dropout=0.05,
    target_modules=["q_proj", "v_proj"],
    task_type="CAUSAL_LM",
)
print(lora_params(4096, 4096, config.r, modules=2))
