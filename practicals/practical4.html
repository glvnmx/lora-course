Практическое задание 4. Варианты и развитие LoRA

Короткая тренировка после лекции: одно задание, которое закрепляет главный навык темы.

Выберите вариант LoRA под задачу

Для каждой ситуации выберите LoRA, QLoRA, DoRA или AdaLoRA и кратко объясните выбор: мало GPU-памяти, нужна максимальная емкость, нужно распределять ранг по слоям, нужен простой baseline.

Мало GPU-памяти -> QLoRA: база хранится в 4-битном виде.
Максимальная емкость -> DoRA: отдельно адаптирует направление и масштаб.
Разный вклад слоев -> AdaLoRA: перераспределяет rank по важности.
Простой baseline -> LoRA: минимальная сложность и хорошая совместимость.
